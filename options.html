Science Tokyo OTP settings

Choose your OTP method. This extension selects that method on the Science Tokyo sign-in page, fills the code, and submits it on isct.ex-tic.com.

Setup key (TOTP)

Enter the key shown by Show secret key on the university's setup page. No QR scan or phone app is required: this extension generates the codes locally. This key is different from the changing six-digit code and your Google password.

Choose a long, unique passphrase. It is not your university password. Click Save settings below to encrypt and save the key. To change the passphrase, unlock first and leave Setup key blank. If you forget the passphrase, you must enter the original key again or enroll a new one at the university.

Unlock once after opening Chrome. It locks again after 30 minutes, on browser restart, or when the extension is reloaded or disabled. No new university secret key is needed. When you unlock, reopen or reload the university's second-factor page to start automatic entry.

If the university asks for a code to finish enrollment, save the key first, then show the current code below and enter it on the university's setup page.

The key is saved locally with AES-256-GCM encryption. Your passphrase and encryption key are not saved. While unlocked, the setup key is held in the extension's session memory. It is not uploaded or synced. Clearing browsing cache does not remove the encrypted key; use Remove saved key. Only the generated code is submitted to the university. Malware or someone controlling this browser while unlocked can still obtain the key.

Gmail OTP email

Gmail access uses the read-only Gmail scope. Authorize the Gmail account that receives messages from noreply@ex-tic.com.
